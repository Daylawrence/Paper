7.3. RGB Image Smoothing Analysis


To enhance robustness in challenging regions characterized
by reﬂections, transparency, or complex textures, we ap-
ply semantic-aware smoothing to the input images prior to
pointmap estimation. The smoothing operation is deﬁned
as ˆy = ε · x + (1 ↑ε) · y, where x is the mean RGB value
of the semantic region, y is the original pixel value, and ε
controls the smoothing strength.


As shown in Table 10, moderate smoothing (ε = 0.1)
provides the optimal balance between noise suppression and
detail preservation. Lower values (ε ↔0.1) insufﬁciently
address visual artifacts, while higher values (ε ↗0.2) over-
smooth genuine structural details, ultimately degrading ge-
ometric accuracy.
