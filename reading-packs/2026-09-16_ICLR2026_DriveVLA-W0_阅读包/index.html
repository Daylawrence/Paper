摘要

在大规模数据上扩展 Vision-Language-Action（VLA，视觉—语言—动作）模型，为实现更通用的驾驶智能提供了有前景的路径。然而，VLA 模型受到“监督不足（supervision deficit）”的限制：巨大的模型容量仅由稀疏、低维动作监督，导致相当一部分表征能力未被充分利用。为解决这一问题，我们提出 DriveVLA-W0，一种通过世界建模预测未来图像的训练范式。该任务产生密集的自监督信号，迫使模型学习驾驶环境的内在动力学。我们分别针对两类主流 VLA 架构实例化该范式，展示其通用性：对于使用离散视觉 token 的 VLA，采用自回归世界模型；对于使用连续视觉特征的 VLA，采用扩散世界模型。基于世界建模学到的丰富表征，我们引入轻量动作专家，解决实时部署中的推理延迟问题。在 NAVSIM v1/v2 基准及规模大 680 倍的内部数据集上进行的大量实验表明，DriveVLA-W0 显著优于 BEV 和 VLA 基线。关键的是，它增强了数据规模定律，表明随着训练集扩大，性能增益会加速增长。

1 引言

规模定律（Kaplan et al., 2020；Zhai et al., 2022；Baniodeh et al., 2025；Dehghani et al., 2023）为更通用的驾驶智能提供了一条有吸引力的路径：有望利用 PB 级驾驶数据训练强大的基础模型。目前主要存在两类范式。一类是围绕 Bird’s-Eye-View（BEV，鸟瞰视图）表征（Li et al., 2022；Huang et al., 2021）构建的专用模型（Hu et al., 2022；Jiang et al., 2023）。它们依赖精心设计的几何先验，这些先验虽对驾驶任务有效，却使非驾驶数据的利用不够直接；此外，相对紧凑的架构可能限制其在大规模数据上的扩展潜力。相应地，VLA 模型（Fu et al., 2025；Li et al., 2025b；Zhou et al., 2025c）成为有前景的替代方案。借助在互联网规模数据上预训练的大型 Vision-Language Model（VLM，视觉语言模型）（Wang et al., 2024b；Bai et al., 2025），VLA 拥有明显更大的模型规模和更强的内在扩展潜力。

然而，这种扩展潜力很大程度上尚未实现，原因在于一个关键挑战：VLA 巨大的模型规模面对的是极其稀疏的监督信号。标准范式仅用专家动作微调 VLM，要求模型把高维传感器输入映射为少量低维控制信号（如路径点），造成严重的“监督不足”。这阻碍模型学习丰富的世界表征，是单纯增加仅动作训练数据量无法克服的根本局限。实际上，我们观察到监督不充分时，大型 VLA 甚至不如更小的专用 BEV 模型。

为解决监督不足，我们利用世界建模（Li et al., 2024a；Wang et al., 2025；Cen et al., 2025；Chen et al., 2024），将它作为密集自监督目标，补充稀疏动作信号。通过要求模型预测未来图像，我们在每个时间步产生密集、丰富的监督信号，迫使模型学习环境内在动力学，构建丰富且具预测性的世界表征。为验证方法有效性，我们在两大 VLA 架构族上实现它；二者主要区别是使用离散 token 还是连续特征表示视觉。对将图像表示为离散视觉 token 的 VLA，世界建模是自然扩展，我们提出自回归世界模型，预测未来图像的离散视觉 token 序列。对使用连续特征的 VLA，这项任务更困难，因为它没有视觉词表，无法直接采用下一 token 预测。为弥补这一缺口，我们引入扩散世界模型，依据当前帧产生的视觉与动作特征，生成未来图像像素。

我们在从学术基准到大规模内部数据集的多个数据规模上验证世界建模方法。首先，学术基准上的扩展实验表明，世界建模对泛化至关重要：它学习稳健的视觉模式，而非过拟合数据集特有的动作模式。随后，我们利用包含 7000 万帧的内部数据集研究真正的规模定律，如图 1 所示。这证实了我们的核心假设：世界建模增强数据规模定律。该优势源于未来帧预测提供的密集视觉监督，形成了一种无法仅靠扩大动作监督数据数量来弥合的质的差距。最后，为实现实时部署，我们引入基于 Mixture-of-Experts（MoE，混合专家）的轻量动作专家。它将动作生成与大型 VLA 骨干解耦，使推理延迟降至基线的 63.1%，也为大规模研究不同动作解码器提供高效试验平台。实验揭示从小数据到大数据时性能趋势发生了显著反转：复杂的流匹配解码器在小数据集上往往占优，但在大规模数据下，简单的自回归解码器表现最好。本文有三项主要贡献：

  • •

    我们将“监督不足”识别为制约 VLA 扩展的关键瓶颈，提出 DriveVLA-W0，通过世界建模从视觉预测中获得密集自监督学习信号。

  • •

    实验揭示世界建模的两个关键规模优势。第一，它通过学习可迁移视觉表征，增强跨动作分布不同领域的泛化。第二，在 7000 万帧的大数据集上，它增强数据规模定律，提供了单纯扩大动作监督数据无法获得的收益。

  • •

    我们引入轻量 MoE 动作专家，使推理延迟降至基线的 63.1%。以它为试验平台，我们揭示动作解码器的规模规律反转：简单自回归模型在大规模数据上超越更复杂的流匹配模型，与小数据集观察到的趋势相反。

2 相关工作

自动驾驶中的 VLA。自动驾驶 VLM 的发展经历了三个主要阶段，从侧重解释逐步走向集成式端到端 VLA 架构。第一阶段是基于语言的场景解释模型，重点在可解释性。DriveGPT4（Xu et al., 2024）等使用大语言模型生成场景说明和高层机动建议，但不产生可直接执行的动作（Chen et al., 2025；Zhou et al., 2025b）。第二阶段是模块化语言到动作框架，旨在连接高层指令与底层控制。这些方法（Zhou et al., 2025a；Yuan et al., 2024；Zhang et al., 2025；Arai et al., 2025；Gao et al., 2025）采用多阶段流程，模块间通过离散文本指令等不可微接口连接，阻断梯度反传。目前的前沿是端到端 VLA（Renz et al., 2025；Renz et al., 2024；Jiang et al., 2025；Hwang et al., 2024；Yang et al., 2025；Zeng et al., 2025），用统一架构直接把传感器输入映射为轨迹。在此范式中，DriveMoE（Yang et al., 2025）引入 MoE 架构，将动作解码器串接在 VLM 骨干后。ReCogDrive（Li et al., 2025b）把 VLM 与通过模仿和强化学习训练的扩散规划器结合，弥合语言—动作差距。AutoVLA（Zhou et al., 2025c）将轨迹 token 化为动作基元，使单个自回归模型学习自适应推理和规划。我们遵循该范式，提出端到端 VLA。

驾驶和机器人中的世界模型。世界模型研究通常遵循两类不同思路：用作仿真数据合成器，或用作表征学习的辅助目标。第一类注重生成，旨在合成高质量驾驶数据。GAIA-1（Hu et al., 2023）、DrivingGPT（Chen et al., 2024）、Doe-1（Zheng et al., 2024a）等生成未来图像或多模态 token，构造逼真场景；Copilot4D（Zhang et al., 2023）则专门预测未来离散视觉 token。第二类利用世界建模作为自监督目标来增强表征学习。VaVAM（Bartoccioni et al., 2025）展示了生成式视频预训练的价值，但缺少动作条件。对此，UniVLA（Wang et al., 2025）和 WorldVLA（Cen et al., 2025）将动作加入自回归预测，学习稳健策略。在自动驾驶领域，LAW（Li et al., 2024a）率先以潜在世界模型探索该范式。与 LAW 预测潜在表征不同，我们监督模型预测未来图像，为 VLA 骨干提供更丰富、更直接的密集学习信号。

3 方法

我们的方法分为三个关键步骤。首先建立 VLA 基线，展示稀疏、仅动作监督带来的挑战。其次，以核心贡献世界建模增强基线，提供密集自监督。在此基础上，引入基于 MoE 的轻量动作专家解决推理瓶颈，确保强大模型具备实时性能。

3.1 VLA 基线

我们的 VLA 基线处理由语言指令（LtL_{t}）、前视图像（VtV_{t}）和历史动作（At−1A_{t-1}）组成的序列。为保证广泛适用性，我们基于两类主流 VLM 构建变体：VLA (VQ) 把图像量化为离散视觉 token，使用 Emu3 风格骨干；VLA (ViT) 提取连续特征，使用 Qwen2.5-VL 风格骨干。

输入 token 化。高层驾驶语言指令（LtL_{t}）使用 VLM 原生 tokenizer 处理。对于历史动作，我们使用 FAST tokenizer（Pertsch et al., 2025）将连续路径点轨迹转换为离散 token 序列，记为 At−1A_{t-1}。

VLM 骨干。在每个时刻 tt，遵循 Wang et al. (2025) 和 Fan et al. (2025)，将 HH 步历史中的多模态片段拼接为深度交错输入序列 StS_{t}：St=[Lt−H,Vt−H,At−H−1,…,Lt,Vt,At−1]S_{t}=[L_{t-H},V_{t-H},A_{t-H-1},\dots,L_{t},V_{t},A_{t-1}]。VLM 骨干使用因果注意力掩码，自回归地处理该序列。我们选择两个代表模型：Emu3 (8B)（Wang et al., 2024b）处理离散视觉表征，Qwen2.5-VL (7B)（Bai et al., 2025）处理连续特征。骨干输出最后一层隐藏状态，再按模态分别拆为语言（FtLF_{t}^{L}）、视觉（FtVF_{t}^{V}）和动作（FtAF_{t}^{A}）特征。

动作预测。训练时，我们用标准交叉熵损失优化模型，使其预测真实动作 token 序列 At=(a1,…,aM)A_{t}=(a_{1},\dots,a_{M})：

ℒAction=−∑i=1LlogP(ai|St,a<i).\mathcal{L}_{\text{Action}}=-\sum_{i=1}^{L}\log P(a_{i}|S_{t},a_{<i}). (1)

推理时，训练好的模型以上下文 StS_{t} 为条件，自回归生成动作 token 序列；再由 FAST detokenizer（Pertsch et al., 2025）将其还原为连续路径点轨迹。

3.2 世界建模

既有 VLA 流程通常只监督动作，产生稀疏监督信号：高维传感器输入被压缩成少量低维控制信号，形成“监督不足”。为此，我们引入世界建模作为强大的自监督目标，并针对两类 VLA 分别实现。对具备离散视觉词表的 VLA，把世界模型表述为下一 token 预测，形成自回归世界模型；对使用连续视觉特征的 VLA，引入扩散世界模型，在连续潜在空间生成未来图像。

自回归世界模型。我们的 AR 世界模型以历史观察和动作为条件，自回归生成当前视觉场景的离散视觉 token 序列，进而预测当前场景（图 2(a)）。

训练。以此前的上下文 S<VtS_{<V_{t}} 为条件，模型学习自回归生成当前图像的视觉 token 序列 Vt=(v1,…,vN)V_{t}=(v_{1},\dots,v_{N})。优化目标是最小化下一 token 预测损失：

ℒWM-AR=−∑i=1NlogP(vi|S<Vt,v<i).\mathcal{L}_{\text{WM-AR}}=-\sum_{i=1}^{N}\log P(v_{i}|S_{<V_{t}},v_{<i}). (2)

我们将这一完整框架称为 DriveVLA-W0 (VQ)。它通过动作损失与 AR 世界模型损失的加权和联合训练：ℒTotal=ℒAction+α​ℒWM-AR\mathcal{L}_{\text{Total}}=\mathcal{L}_{\text{Action}}+\alpha\mathcal{L}_{\text{WM-AR}}，其中 α\alpha 是平衡系数。

推理。为保证低延迟，驾驶推理通常跳过显式视觉 token 生成，但该能力仍可用于可视化。生成图像时，模型自回归采样视觉 token 序列，再通过 MoVQGAN（Zheng et al., 2022）解码器渲染最终图像 I^t\hat{I}_{t}。

扩散世界模型。不同于 VQ 版本，VLA (ViT) 没有适合下一 token 预测的离散视觉词表。因此，我们引入扩散世界模型，通过训练潜在扩散模型（Rombach et al., 2021；Wang et al., 2024a），以 VLA 丰富的输出特征（FtV,FtAF_{t}^{V},F_{t}^{A}）为条件生成未来图像，提供密集监督（图 2）。选择预测未来帧（𝐈t+1\mathbf{I}_{t+1}）至关重要：模型同时以全部当前特征为条件，因此必须预测未来，才能学习预测性动力学，而非仅执行重建。

训练。该框架以 VLA 当前视觉与动作特征（FtVF_{t}^{V}、FtAF_{t}^{A}）为条件，学习预测未来视觉场景（𝐈t+1\mathbf{I}_{t+1}）。遵循标准潜在扩散设置，训练模型对未来图像潜在表征的加噪版本去噪，使用 MSE（均方误差）目标优化：

ℒWM-Diff=𝔼zt+1,ϵ,k​[‖ϵ−ϵ^​(zt+1,k,k,FtV,FtA)‖2].\mathcal{L}_{\text{WM-Diff}}=\mathbb{E}_{z_{t+1},\epsilon,k}\left[\|\epsilon-\hat{\epsilon}(z_{t+1,k},k,F_{t}^{V},F_{t}^{A})\|^{2}\right]. (3)

其中 zt+1z_{t+1} 是未来图像 𝐈t+1\mathbf{I}_{t+1} 的潜在表征，ϵ∼𝒩⁡(0,𝐈)\epsilon\sim\mathcal{N}(0,\mathbf{I}) 是采样的高斯噪声，kk 是随机扩散时间步，ϵ^\hat{\epsilon} 是去噪网络，它从带噪潜变量 zt+1,kz_{t+1,k} 中预测噪声。我们将整体框架称为 DriveVLA-W0 (ViT)。通过联合目标结合动作预测与扩散世界模型损失，进行端到端训练：ℒTotal=ℒAction+β​ℒWM-Diff\mathcal{L}_{\text{Total}}=\mathcal{L}_{\text{Action}}+\beta\mathcal{L}_{\text{WM-Diff}}，其中 β\beta 为平衡系数。

推理。与 AR 模型一样，驾驶推理跳过扩散过程以保证实时性能。进行定性分析时，可以从随机噪声开始，以特征 FtVF_{t}^{V}、FtAF_{t}^{A} 为条件执行反向扩散，产生预测的未来图像 I^t+1\hat{I}_{t+1}。

3.3 动作专家

MoE 架构。（Black et al.；Intelligence et al., 2025）大型 VLA 骨干擅长表征学习，但其规模妨碍实时控制。为此，我们引入 500M 参数的轻量动作专家，与主 VLA 专家（完整 VLA 骨干）在 MoE 架构中并行工作。动作专家的 Transformer 块结构与 VLA 专家相似，但隐藏维度小得多。这种结构相似性通过 Joint Attention（联合注意力）实现深度、高效的信息融合，如图 3(a)。两个专家先各自计算 Query、Key、Value 矩阵，再沿 token 序列维拼接为联合注意力的输入：

Q=[QVLA;QAE],K=[KVLA;KAE],V=[VVLA;VAE].Q=[Q_{\text{VLA}};Q_{\text{AE}}],\quad K=[K_{\text{VLA}};K_{\text{AE}}],\quad V=[V_{\text{VLA}};V_{\text{AE}}]. (4)

随后将注意力输出拆分，送回各自专家，如图 3。这使 VLA 丰富表征与动作专家专用上下文，能在一次高效计算中紧密、对称地整合。

该高效 MoE 架构也为系统研究三种动作解码策略提供理想平台：基于查询、自回归和流匹配专家。这些变体的一个共同点，是预填充前一动作的特征（At−1A_{t-1}），为当前决策提供强时序先验。

基于查询的动作专家。该专家使用一组可学习动作查询，通过联合注意力与 VLA 多模态上下文交互。更新后的查询由 MLP 头投影，直接回归连续路径点轨迹。模型以预测轨迹与真实轨迹间的 L1 距离最小化为目标。

自回归动作专家。该专家通过自回归预测离散 token 序列来生成动作。其训练目标与表述和第 3.1 节的 VLA 基线相同，即最小化标准交叉熵损失。

流匹配动作专家。不同于离散的自回归方法，我们还实现了基于流匹配的连续动作生成。该方法学习条件向量场 vϕv_{\phi}，定义从简单噪声分布到复杂真实驾驶动作分布的直接“路径”。训练时，在随机噪声样本与真实动作之间定义简单直线路径（Liu et al., 2022）；随后用均方误差损失优化模型，使其以多模态上下文 𝐜t\mathbf{c}_{t} 为条件，在每个位置预测与路径对齐的向量场 vϕv_{\phi}。推理时，从新噪声样本开始，使用数值 ODE 求解器，沿学到的向量场走固定步数，将噪声确定性地转成位于已学数据流形上的精确连续动作。

4 实验

4.1 数据集

NAVSIM。我们使用由 OpenScene（Contributors, 2023）衍生的 NAVSIM（Dauner et al., 2024）基准，评估安全关键场景中的性能。

NAVSIM v1 指标包括无责任碰撞（NC）、可行驶区域合规（DAC）、碰撞时间（TTC）、舒适度（C.）和自车进度（EP）。NAVSIM 使用预测驾驶员模型分数（PDMS）评估模型性能：P​D​M​S=N​C×D​A​C×5×E​P+5×T​T​C+2×C.12PDMS=NC\times DAC\times\frac{5\times EP+5\times TTC+2\times C.}{12}。

NAVSIM v2（Cao et al., 2025）包含被分为惩罚项与加权子分数的多个组成部分。关键指标是无责任碰撞（NC）、可行驶区域合规（DAC）、行驶方向合规（DDC）、交通灯合规（TLC）、自车进度（EP）、碰撞时间（TTC）、车道保持（LK）、历史舒适度（HC）和扩展舒适度（EC）。它使用扩展预测驾驶员模型分数（EPDMS）评估性能：EPDMS=NC×DAC×DDC×TLC×5×EP+5×TTC+2×LK+2×HC+2×EC16\text{EPDMS}=\text{NC}\times\text{DAC}\times\text{DDC}\times\text{TLC}\times\frac{5\times\text{EP}+5\times\text{TTC}+2\times\text{LK}+2\times\text{HC}+2\times\text{EC}}{16}。

内部数据集。为检验超出学术基准的数据可扩展性，我们使用大规模内部数据集训练和评估。训练集含 7000 万帧，来自超过 100 万个不重复片段，经过整理以保证广泛驾驶场景的多样性与平衡性，并显著增加挑战性、安全关键事件的比例。测试集包含 100 个挑战场景。轨迹评估使用未来 3 秒、6 路径点（2 Hz）的平均位移误差（ADE）；安全性使用碰撞率，计算方法与 NAVSIM 的无责任碰撞（NC）指标相同。

4.2 实现细节

两阶段训练范式。模型采用两阶段训练：先学习丰富世界表征，再专门学习动作生成。第一阶段以 6VA 序列配置预训练 VLA 骨干，用世界模型损失与动作预测损失的联合目标优化。第二阶段接入动作专家，骨干改为处理 2VA 输入序列。我们不冻结 VLA 骨干，但模型仅由动作专家部分的动作损失监督。

NAVSIM。基准实验中，模型先在 NuPlan（Caesar et al., 2021）预训练 8k 步，再在 NAVSIM 微调 4k 步，图像分辨率为 256×144。训练使用 8 张 NVIDIA L20、全局 batch size 48，AdamW 优化器、余弦学习率调度、初始学习率 2e-4，以及 bfloat16 混合精度。消融实验默认选用架构较简单的 DriveVLA-W0 (VQ)。

内部数据集。大规模内部实验使用相同数据预训练 50k 步、微调 30k 步；使用 64 张 GPU 的集群，全局 batch size 256。优化器和学习率调度与 NAVSIM 设置相同。

重新实现的 TransFuser。为内部数据集提供强基线，我们改造并重新实现著名的 TransFuser（Prakash et al., 2021）架构。为与单相机设置公平比较，我们将仅图像版 Latent-TransFuser 从多视图输入改成单个前视图。为研究模型规模影响，我们实现 50M 与 7B 两个版本：较小的 TransFuser-50M 使用标准 ResNet-34；较大的 TransFuser-7B 使用 ViT-7B 骨干，以 DINOv3（Siméoni et al., 2025）预训练权重初始化。

4.3 与最先进方法比较

如表 1、表 2 所示，DriveVLA-W0 超越不同架构范式中的领先方法，包括基于 BEV 的 WoTE（Li et al., 2025a）和基于 VLA 的 AutoVLA（Zhou et al., 2025c），在 NAVSIM 上达到新的最先进水平。特别是，本模型仅用单个前视相机，就超过了使用多相机加 LiDAR 等更丰富传感器配置的竞争方法。这种优异表现归功于世界建模目标提供的强大密集监督，使模型学到更有效的特征表征。

4.4 世界模型增强数据规模定律

世界建模随数据扩展释放泛化能力。为测试不同动作分布间的泛化，我们先在大规模 NuPlan 预训练，再在聚焦挑战性长尾机动的小型基准 NAVSIM 微调。该设置的视觉域仍相似，但动作空间存在明显域偏移，给知识迁移带来挑战。如图 4、表 7 所示，世界建模对有效迁移至关重要。我们观察到两种相反趋势：1）仅依赖稀疏动作监督的基线常因预训练受损，例如 TransFuser-7B 与 VLA (VQ) 基线显著下降（红箭头），因为过拟合 NuPlan 动作分布形成了不利先验，妨碍适应 NAVSIM 边缘场景；2）VLA-W0 始终从预训练获益。要求模型预测未来视觉帧，促使它学习可迁移的环境视觉表征，从而获得更强泛化能力。

随数据扩展，世界建模优于仅动作监督。我们在三种数据规模（70k、700k、70M 帧）上训练模型，研究数据可扩展性。为清晰消融世界建模范式的作用，这些实验直接在基础 VLA 上进行，不使用动作专家。如表 3，世界模型是释放大数据收益的关键。仅依赖稀疏动作监督的基线很快饱和，而 DriveVLA-W0 持续改善。在 70M 帧时效果最明显：加入世界建模后，VQ 模型的 ADE 改善 28.8%，ViT 模型碰撞率改善 15.9%。这表明，即使有海量训练数据，仅动作监督也无法复制密集世界模型目标带来的质的优势。〔译注：这里原文写 70k、700k、70M；图 1 的横轴为 700K、7M、70M，原文如此。〕

动作专家的性能随数据扩展发生反转。比较 NAVSIM（100k 帧）与内部数据集（70M 帧）上的动作专家，发现由预测精度和建模能力权衡所驱动的明显反转。如表 4，小规模 NAVSIM 上轨迹分布简单，查询式与流匹配等连续解码器表现出色：较高精度使它们优于受量化误差影响的离散自回归方法。但在大数据集上，主要挑战变为建模远更复杂的轨迹分布。此时，自回归解码器强大的建模能力及样本高效的 teacher-forced（教师强制）训练，使其最能有效扩展。相比之下，查询专家遇到表征瓶颈；流匹配专家则因样本效率过低，无法在复杂数据流形上收敛，从而出现上述性能反转。

4.5 消融研究

下面两项世界模型消融均不使用动作专家。

纯视觉与视觉—动作序列。如表 6，使用交错视觉—动作序列（6VA）预训练，相比仅用视觉损失预训练（6V）的基线显著改善，PDMS 从 84.1 升至 85.6。这说明让视觉预测以相应自车动作为依据至关重要：它要求模型预测特定动作导致的视觉结果，而非泛化、模糊的未来，促使模型学习环境内在的因果动力学。〔译注：正文引用表 6；纯视觉/视觉—动作对比的实际表题是表 5，原文如此。〕

序列长度消融。我们用 VA、2VA、6VA 三种配置消融预训练序列长度。表 6 揭示明确趋势：性能随时序上下文扩展而提升，最长 6VA 表现最好。这表明更长上下文窗口对学习复杂、长时域环境动力学至关重要，因为它能更好捕获规划所需的时间依赖。

延迟消融。我们在 H200 GPU 上测量推理延迟以验证 MoE 效率。相比 DriveVLA-W0 基线（117.8 ms、85.6 PDMS），加入基于查询的 MoE 专家后，延迟显著降至 74.3 ms（原来的 63.1%），同时 PDMS 提高到 88.4。更多分析见附录 B.1。

4.6 可视化

除优异规划性能外，DriveVLA-W0 还展现出强大的动作条件未来生成能力，表明它有潜力作为反应式仿真器。如图 5，我们显式给模型输入反事实“减速”轨迹；生成帧中，周围场景经过车辆的速度明显低于真实数据。这种控制信号与视觉动态的精确对齐证实了模型扎根于物理的理解能力。更多定性分析见附录 C，包括轨迹可视化与案例比较（图 7、8、9、10）、未来图像生成（图 13）和反事实推理（图 14）。

5 结论

本文将“监督不足”识别为阻碍自动驾驶 VLA 可扩展性的根本瓶颈，提出 DriveVLA-W0，以未来图像预测作为密集自监督目标解决它，并适配 VQ 和 ViT 架构。大量实验表明，相比基线，该方法不仅释放更强的数据可扩展性和泛化能力，还揭示动作解码器随规模增长的性能反转，最终由更简单的自回归模型胜出。我们的发现表明，要在追求更通用驾驶智能的过程中释放大规模数据的全部潜力，采用密集、预测式世界建模是关键一步。

大 VLA 只用少量路径点监督时，如何获得足够密集的学习信号、随数据规模持续提升，并在实时预算内输出动作？

5. 方法流程

历史语言、视觉与动作组成交错序列→Emu3 离散视觉 token 或 Qwen2.5-VL 连续特征→第一阶段联合动作预测和未来图像预测→第二阶段接入动作专家，VLA 与动作专家逐层联合注意力→查询式、AR 或流匹配解码轨迹。详见算法 1至算法 3与公式章节。

6. 真正创新点

真正贡献是把未来图像生成作为驾驶 VLA 的密集自监督目标，并在 VQ、ViT 两类骨干上分别实现；同时用并行 MoE 动作专家研究解码器随数据规模的性能反转。Emu3、Qwen2.5-VL、MoVQGAN、潜在扩散、FAST tokenizer、flow matching 均为沿用模块。下方对比表给出瓶颈、修改和证据。

12. 两个面试问题

Q1：为什么未来图像预测比只加更多动作数据更可能解决监督不足？答：每帧图像/潜变量提供高维密集目标，并要求表征保留对象、几何和动态；仅路径点仍把复杂场景压成少量数。但视觉 loss 也可能学外观捷径，必须用动作条件和规划指标验证。

Q2：为什么小数据上 Flow/Query 更强，大数据上 AR 反超？答：小数据轨迹分布较简单，连续解码无量化误差；复杂分布下，AR 的 token 条件分解、teacher forcing 和建模容量更易扩展。论文表 4 是实证，不能提升为所有任务的普遍定理。

13. 迁移实验

在 Qwen2.5-VL 路线加入冻结的 VGGT/Depth Pro 几何 token：以相邻两帧预测未来深度、可见性与 RGB latent，多任务 loss 与动作 loss 联合；YOLO 目标转换为带深度、速度和置信度的对象 token。做 RGB-only、RGB＋深度、RGB＋深度但打乱时序、RGB＋真实动作/反事实动作四组；同数据量、训练步、优化器，按 NAVSIM NC/TTC/EP、未来深度误差、目标召回和延迟比较。若未来图像更清晰但动态对象召回或 NC 下降，应拒绝“世界理解更强”的结论。

算法 1：双路线世界模型联合训练

  1. 问题与衔接：把稀疏动作监督补成密集预测目标。VQ 输入为交错 L/V/A token；ViT 输入为 Qwen 特征，目标是下一帧 VAE latent。
  2. 形状：B 批量，H 历史步，N 视觉 token 数，M 动作 token 数，C 隐藏维，z∈R^[B,C_z,H_z,W_z]。VQ 序列 S=[L,V,A,…]；ViT 条件视觉特征重排为 [B,C,10,18]，动作特征平均后为 [B,C]；未来 latent 约 [B,C_z,H_z,W_z]，准确尺寸由 VAE/输入决定。
  3. 预处理/掩码：语言使用原 tokenizer，路径点由 FAST 离散化。数据代码把非目标 token 的 label 置 −100；纯视觉设置只保留视觉范围。ViT 代码断言每样本两帧，取 t 的 image/action hidden，VAE 在 no_grad 中编码 t+1；扩散时间 k 均匀采样。
  4. 训练/梯度：VQ 交叉熵梯度回到完整 VLA。ViT 总 loss 是基础 action loss＋ross_loss；VAE 冻结，UNet requires_grad=True，视觉/动作条件从 VLA hidden 进入 denoiser，所以世界 loss 可回传至 VLA。第一阶段联合训练；第二阶段论文说明骨干不冻结但只收动作专家 loss。
  5. 推理：驾驶时跳过视觉生成；可视化才 AR 生成 token 并用 MoVQGAN 解码，或运行扩散反向过程。
  6. 小例：视觉 token 真值概率 [.8,.5]，AR loss=−ln.8−ln.5≈.9163；action loss=.4、α=.5，总 loss=.8582。扩散单元素 ε=.6、预测 .4，MSE=.04；β=.5 时给总 loss 增 .02。

算法 2：动作专家的 Joint Attention

  1. 问题：让小动作专家读取大 VLA 表征，同时减少完整骨干逐 token 解码的延迟。
  2. 形状：VLA hidden [B,L_v,C_v]、动作 hidden [B,L_a,C_a]；各自投影为 Q [B,h,L,d]、K/V [B,h_kv,L,d]。沿序列维拼成总长度 L_v+L_a，注意力输出再拆回两个专家。
  3. 前向/掩码：VLA Q/K 使用 RoPE，动作专家 Q/K 不使用；repeat_kv 后调用 scaled_dot_product_attention。VLA 内部 causal＋padding；动作部分可双向或因果。Flow 路径中动作专家只能看第二个 BOA 之前的 VLA 内容；推理预计算并缓存 VLA K/V。
  4. 训练/梯度：联合注意力没有 detach，动作 loss 通过 VLA 的 K/V 回到骨干；论文第二阶段不冻结 VLA。每个专家保持自己的 MLP、norm 和投影，注意力输出按序列拆分。
  5. 推理：VLA context 算一次；Flow 的 10 步复用 VLA K/V，仅重复动作专家路径。AR 按 token 长度串行，Query 单前向。
  6. 手算：一个 VLA key 和一个 action key 的 logits=[0,ln3]，softmax=[.25,.75]；value=[2,6] 时动作 query 输出 5。若 mask 禁止未来动作 key，其权重归零。

算法 3：Flow Matching 动作生成

  1. 问题：从噪声连续生成 8 帧、每帧 3 维的轨迹，避免离散 token 量化。
  2. 形状：真实动作 x、噪声 z₁、插值 z_t 和速度预测均 [B,8,3]；t=[B] 广播为 [B,1,1]。另有历史动作与命令组成的 state token。
  3. 采样/前向：t 默认从 s·(1−Beta(1.5,1.0)) 采样，s=.999；z_t=(1−t)x+t z₁。动作 projector 把 z_t 与 t embedding 转为 token，经 Joint Attention，decoder 预测速度。
  4. 训练/梯度：目标速度 z₁−x，MSE 更新动作专家、decoder 和未冻结 VLA。脚本 freeze_vlm=False、action_sample_steps=10；公开实现 action_loss_weight=1、vlm_loss_weight=0。
  5. 推理：从 t=1 噪声开始，dt=−1/S，S 默认 10；每步 z←z+dt·v，直到 0。缓存 VLA K/V；无 classifier-free guidance。
  6. 小例：x=2、z₁=−1、t=.25，则 z_t=1.25，目标 v=−3。若模型准确且 dt=−.1，一步 z 变为 1.55；沿反向时间累计从 −1 回到 2。

关键数学公式逐式解释

式（1）：动作自回归交叉熵

$$\mathcal L_{Action}=-\sum_{i=1}^{M}\log P(a_i\mid S_t,a_{<i}).\tag{1}$$

a_i 是动作 token，M 为 token 数，S_t 为多模态上下文。右边逐 token 取真实类别的负对数概率；teacher forcing 使训练并行，推理仍串行。真值概率 [.8,.5] 时 loss=.9163。梯度提高真实 token logit。相比连续 L1，它能表达复杂条件分布但有量化误差。对应 AR action loss · reference/Emu3/emu3/mllm/modeling_emu3.py:3472-3514。

式（2）：AR 世界模型

$$\mathcal L_{WM-AR}=-\sum_{i=1}^{N}\log P(v_i\mid S_{<V_t},v_{<i}).\tag{2}$$

v_i 是离散视觉 token，N 为视觉 token 数，S 含此前语言、视觉和动作。计算与式（1）相同，但 label mask 只保留目标视觉位置。两 token 概率 [.9,.25] 时 loss≈1.4917。它提供密集监督，但受 codebook 量化并可能偏重纹理。总 VQ 目标为 L_Action＋αL_WM-AR；α 控制两类梯度。

式（3）：扩散世界模型 MSE

$$\mathcal L_{WM-Diff}=\mathbb E_{z_{t+1},\epsilon,k}\left[\|\epsilon-\hat\epsilon(z_{t+1,k},k,F_t^V,F_t^A)\|^2\right].\tag{3}$$

z_{t+1}∈R^[B,C_z,H_z,W_z] 是下一帧 latent，ε 同形高斯，k=[B] 为时间步；F_t^V/F_t^A 是当前视觉/动作条件。先冻结 VAE 编码下一帧，再加噪预测目标。ε=.6、预测 .4 时误差 .04，梯度为 −.4。MSE 适合高斯扩散且避免视觉词表；代价是 UNet/VAE。若 scheduler 为 v_prediction，代码把目标切换为 velocity；总 ViT 目标为 L_Action＋βL_WM-Diff。

式（4）：Joint Attention 拼接

$$Q=[Q_{VLA};Q_{AE}],\quad K=[K_{VLA};K_{AE}],\quad V=[V_{VLA};V_{AE}].\tag{4}$$

分号为 token 维拼接。Q_VLA=[B,h,L_v,d]、Q_AE=[B,h,L_a,d]，结果 [B,h,L_v+L_a,d]；注意力矩阵为 [B,h,L_v+L_a,L_v+L_a]，再拆回专家。mask 控制动作能否看见未来。拼接让动作 loss 更新 VLA 表征；简单串接网络则交互更浅。

补充解释式：Flow Matching

$$z_t=(1-t)x+t\epsilon,\quad u_t=\epsilon-x,\quad \mathcal L_{FM}=\mathbb E\|v_\phi(z_t,t,c)-u_t\|^2.$$

这是公开代码的实现展开，不冒充论文编号。x、ε、z_t、u_t∈R^[B,8,3]；c 为上下文。t=0 是数据、t=1 是噪声；速度沿直线恒为 ε−x。例 x=2、ε=−1，u=−3；推理 dt=−.1，更新量 +.3，朝数据移动。它比一次 L1 更能表达条件连续分布，但要多次调用网络。

评价公式：PDMS/EPDMS

$$PDMS=NC\cdot DAC\cdot\frac{5EP+5TTC+2C}{12}.$$

NC、DAC 是乘法门控；EP/TTC 权重各 5，舒适度权重 2。NC=.98、DAC=.96、EP=.82、TTC=.95、C=1 时 PDMS≈78.4。该指标不可微，只用于评估。EPDMS 再乘 DDC/TLC，分子增加 2LK＋2HC＋2EC，分母 16；版本间分数不可直接横比。评估由外部 NAVSIM 仓库执行，当前仓库只提供调用脚本。
