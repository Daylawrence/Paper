完整 13 项学习简报

1. 基本信息

Yingyan Li、Shuyao Shang、Weisong Liu 等；中国科学院自动化研究所与引望智能。ICLR 2026。阅读和翻译选定 arXiv:2510.12796v2（22 页，含附录）；ICLR 正式入口。官方仓库 BraveGroup/DriveVLA-W0，固定 commit a55766ce46ee55d9035b93816e57b8d933166482。VQ 路线基于 Emu3 8B，ViT 路线基于 Qwen2.5-VL 7B，动作专家约 500M。

2. 分类标签

自动驾驶 VLA · 世界模型 · 自回归视觉 token · 潜在扩散 · MoE 动作专家 · 流匹配 · 数据规模定律。

3. 个性化学习理由

你的 Qwen2.5-VL LoRA/SFT 经历能直接映射到 ViT 世界模型；VGGT、Depth Pro、YOLO 项目可提供几何和动态目标表征。本文补足的是如何用未来视觉监督迫使驾驶 VLA 学到环境动力学，以及如何把大模型表征交给低延迟连续动作头。

4. 一句话问题定义

大 VLA 只用少量路径点监督时，如何获得足够密集的学习信号、随数据规模持续提升，并在实时预算内输出动作？

5. 方法流程

历史语言、视觉与动作组成交错序列→Emu3 离散视觉 token 或 Qwen2.5-VL 连续特征→第一阶段联合动作预测和未来图像预测→第二阶段接入动作专家，VLA 与动作专家逐层联合注意力→查询式、AR 或流匹配解码轨迹。详见算法 1至算法 3与公式章节。

6. 真正创新点

真正贡献是把未来图像生成作为驾驶 VLA 的密集自监督目标，并在 VQ、ViT 两类骨干上分别实现；同时用并行 MoE 动作专家研究解码器随数据规模的性能反转。Emu3、Qwen2.5-VL、MoVQGAN、潜在扩散、FAST tokenizer、flow matching 均为沿用模块。下方对比表给出瓶颈、修改和证据。

7. 实验与证据

论文报告：NAVSIM v1 单前视相机版本最高 93.0 PDMS（AR expert＋best-of-6）；查询式单轨迹为 88.4。NAVSIM v2 为 86.1 EPDMS。70M 帧时，VQ 世界模型 ADE 改善 28.8%，ViT 世界模型碰撞率改善 15.9%；动作专家从小数据的 Query 领先反转为 70M 上 AR 最佳。MoE Query 延迟 74.3 ms，对比基线 117.8 ms，为 63.1%。源码静态分析：已读取固定 commit；公开代码确认交错标签、扩散噪声目标、联合 Q/K/V、流匹配和 KV cache。实际运行验证：仅进行独立公式/形状小样例及阅读包离线验收；未下载 checkpoint、NuPlan/NAVSIM 或运行 GPU 评测，不能称已复现。

12. 两个面试问题

Q1：为什么未来图像预测比只加更多动作数据更可能解决监督不足？答：每帧图像/潜变量提供高维密集目标，并要求表征保留对象、几何和动态；仅路径点仍把复杂场景压成少量数。但视觉 loss 也可能学外观捷径，必须用动作条件和规划指标验证。

Q2：为什么小数据上 Flow/Query 更强，大数据上 AR 反超？答：小数据轨迹分布较简单，连续解码无量化误差；复杂分布下，AR 的 token 条件分解、teacher forcing 和建模容量更易扩展。论文表 4 是实证，不能提升为所有任务的普遍定理。

13. 迁移实验

在 Qwen2.5-VL 路线加入冻结的 VGGT/Depth Pro 几何 token：以相邻两帧预测未来深度、可见性与 RGB latent，多任务 loss 与动作 loss 联合；YOLO 目标转换为带深度、速度和置信度的对象 token。做 RGB-only、RGB＋深度、RGB＋深度但打乱时序、RGB＋真实动作/反事实动作四组；同数据量、训练步、优化器，按 NAVSIM NC/TTC/EP、未来深度误差、目标召回和延迟比较。若未来图像更清晰但动态对象召回或 NC 下降，应拒绝“世界理解更强”的结论。

算法 1：双路线世界模型联合训练

  1. 问题与衔接：把稀疏动作监督补成密集预测目标。VQ 输入为交错 L/V/A token；ViT 输入为 Qwen 特征，目标是下一帧 VAE latent。
  2. 形状：B 批量，H 历史步，N 视觉 token 数，M 动作 token 数，C 隐藏维，z∈R^[B,C_z,H_z,W_z]。VQ 序列 S=[L,V,A,…]；ViT 条件视觉特征重排为 [B,C,10,18]，动作特征平均后为 [B,C]；未来 latent 约 [B,C_z,H_z,W_z]，准确尺寸由 VAE/输入决定。
  3. 预处理/掩码：语言使用原 tokenizer，路径点由 FAST 离散化。数据代码把非目标 token 的 label 置 −100；纯视觉设置只保留视觉范围。ViT 代码断言每样本两帧，取 t 的 image/action hidden，VAE 在 no_grad 中编码 t+1；扩散时间 k 均匀采样。
  4. 训练/梯度：VQ 交叉熵梯度回到完整 VLA。ViT 总 loss 是基础 action loss＋ross_loss；VAE 冻结，UNet requires_grad=True，视觉/动作条件从 VLA hidden 进入 denoiser，所以世界 loss 可回传至 VLA。第一阶段联合训练；第二阶段论文说明骨干不冻结但只收动作专家 loss。
  5. 推理：驾驶时跳过视觉生成；可视化才 AR 生成 token 并用 MoVQGAN 解码，或运行扩散反向过程。
  6. 小例：视觉 token 真值概率 [.8,.5]，AR loss=−ln.8−ln.5≈.9163；action loss=.4、α=.5，总 loss=.8582。扩散单元素 ε=.6、预测 .4，MSE=.04；β=.5 时给总 loss 增 .02。

算法 2：动作专家的 Joint Attention

  1. 问题：让小动作专家读取大 VLA 表征，同时减少完整骨干逐 token 解码的延迟。
  2. 形状：VLA hidden [B,L_v,C_v]、动作 hidden [B,L_a,C_a]；各自投影为 Q [B,h,L,d]、K/V [B,h_kv,L,d]。沿序列维拼成总长度 L_v+L_a，注意力输出再拆回两个专家。
  3. 前向/掩码：VLA Q/K 使用 RoPE，动作专家 Q/K 不使用；repeat_kv 后调用 scaled_dot_product_attention。VLA 内部 causal＋padding；动作部分可双向或因果。Flow 路径中动作专家只能看第二个 BOA 之前的 VLA 内容；推理预计算并缓存 VLA K/V。
  4. 训练/梯度：联合注意力没有 detach，动作 loss 通过 VLA 的 K/V 回到骨干；论文第二阶段不冻结 VLA。每个专家保持自己的 MLP、norm 和投影，注意力输出按序列拆分。
  5. 推理：VLA context 算一次；Flow 的 10 步复用 VLA K/V，仅重复动作专家路径。AR 按 token 长度串行，Query 单前向。
  6. 手算：一个 VLA key 和一个 action key 的 logits=[0,ln3]，softmax=[.25,.75]；value=[2,6] 时动作 query 输出 5。若 mask 禁止未来动作 key，其权重归零。
  7. 自行编写示意伪代码：
    qv,kv,vv = vlm.project(norm(hv)); qa,ka,va = ae.project(norm(ha))
q = concat(rope(qv), qa, dim=tokens)
k = concat(rope(kv), ka, dim=tokens)
v = concat(vv, va, dim=tokens)
o = attention(q,k,v,mask)
hv, ha = split(o, [Lv,La]); hv=vlm_mlp(hv); ha=ae_mlp(ha)
  8. 源码：联合 Q/K/V 与拆分 · reference/Emu3/emu3/mllm/modeling_emu3.py:1760-1850；因果与可见性 mask · reference/Emu3/emu3/mllm/modeling_emu3.py:2580-2668；KV cache 和流匹配采样 · reference/Emu3/emu3/mllm/modeling_emu3.py:2370-2433。
  9. 误区：这是两个专家在每层共享一次注意力运算，不是路由器从专家池里 top-k 选专家；不能直接套用稀疏路由复杂度结论。

算法 3：Flow Matching 动作生成

  1. 问题：从噪声连续生成 8 帧、每帧 3 维的轨迹，避免离散 token 量化。
  2. 形状：真实动作 x、噪声 z₁、插值 z_t 和速度预测均 [B,8,3]；t=[B] 广播为 [B,1,1]。另有历史动作与命令组成的 state token。
  3. 采样/前向：t 默认从 s·(1−Beta(1.5,1.0)) 采样，s=.999；z_t=(1−t)x+t z₁。动作 projector 把 z_t 与 t embedding 转为 token，经 Joint Attention，decoder 预测速度。
  4. 训练/梯度：目标速度 z₁−x，MSE 更新动作专家、decoder 和未冻结 VLA。脚本 freeze_vlm=False、action_sample_steps=10；公开实现 action_loss_weight=1、vlm_loss_weight=0。
  5. 推理：从 t=1 噪声开始，dt=−1/S，S 默认 10；每步 z←z+dt·v，直到 0。缓存 VLA K/V；无 classifier-free guidance。
  6. 小例：x=2、z₁=−1、t=.25，则 z_t=1.25，目标 v=−3。若模型准确且 dt=−.1，一步 z 变为 1.55；沿反向时间累计从 −1 回到 2。
  7. 自行编写示意伪代码：

z_t = (1-t)*action + t*noise

loss = mse(v, noise-action)
z = randn(B,8,3)
for t in linspace(1,0,10): z = z - 0.1 * expert(z,t,cached_context)

关键数学公式逐式解释

式（1）：动作自回归交叉熵

$$\mathcal L_{Action}=-\sum_{i=1}^{M}\log P(a_i\mid S_t,a_{<i}).\tag{1}$$

a_i 是动作 token，M 为 token 数，S_t 为多模态上下文。右边逐 token 取真实类别的负对数概率；teacher forcing 使训练并行，推理仍串行。真值概率 [.8,.5] 时 loss=.9163。梯度提高真实 token logit。相比连续 L1，它能表达复杂条件分布但有量化误差。对应 AR action loss · reference/Emu3/emu3/mllm/modeling_emu3.py:3472-3514。

式（2）：AR 世界模型

$$\mathcal L_{WM-AR}=-\sum_{i=1}^{N}\log P(v_i\mid S_{<V_t},v_{<i}).\tag{2}$$

v_i 是离散视觉 token，N 为视觉 token 数，S 含此前语言、视觉和动作。计算与式（1）相同，但 label mask 只保留目标视觉位置。两 token 概率 [.9,.25] 时 loss≈1.4917。它提供密集监督，但受 codebook 量化并可能偏重纹理。总 VQ 目标为 L_Action＋αL_WM-AR；α 控制两类梯度。

式（3）：扩散世界模型 MSE

$$\mathcal L_{WM-Diff}=\mathbb E_{z_{t+1},\epsilon,k}\left[\|\epsilon-\hat\epsilon(z_{t+1,k},k,F_t^V,F_t^A)\|^2\right].\tag{3}$$

z_{t+1}∈R^[B,C_z,H_z,W_z] 是下一帧 latent，ε 同形高斯，k=[B] 为时间步；F_t^V/F_t^A 是当前视觉/动作条件。先冻结 VAE 编码下一帧，再加噪预测目标。ε=.6、预测 .4 时误差 .04，梯度为 −.4。MSE 适合高斯扩散且避免视觉词表；代价是 UNet/VAE。若 scheduler 为 v_prediction，代码把目标切换为 velocity；总 ViT 目标为 L_Action＋βL_WM-Diff。

式（4）：Joint Attention 拼接

$$Q=[Q_{VLA};Q_{AE}],\quad K=[K_{VLA};K_{AE}],\quad V=[V_{VLA};V_{AE}].\tag{4}$$

分号为 token 维拼接。Q_VLA=[B,h,L_v,d]、Q_AE=[B,h,L_a,d]，结果 [B,h,L_v+L_a,d]；注意力矩阵为 [B,h,L_v+L_a,L_v+L_a]，再拆回专家。mask 控制动作能否看见未来。拼接让动作 loss 更新 VLA 表征；简单串接网络则交互更浅。

补充解释式：Flow Matching

$$z_t=(1-t)x+t\epsilon,\quad u_t=\epsilon-x,\quad \mathcal L_{FM}=\mathbb E\|v_\phi(z_t,t,c)-u_t\|^2.$$

这是公开代码的实现展开，不冒充论文编号。x、ε、z_t、u_t∈R^[B,8,3]；c 为上下文。t=0 是数据、t=1 是噪声；速度沿直线恒为 ε−x。例 x=2、ε=−1，u=−3；推理 dt=−.1，更新量 +.3，朝数据移动。它比一次 L1 更能表达条件连续分布，但要多次调用网络。

评价公式：PDMS/EPDMS

$$PDMS=NC\cdot DAC\cdot\frac{5EP+5TTC+2C}{12}.$$

NC、DAC 是乘法门控；EP/TTC 权重各 5，舒适度权重 2。NC=.98、DAC=.96、EP=.82、TTC=.95、C=1 时 PDMS≈78.4。该指标不可微，只用于评估。EPDMS 再乘 DDC/TLC，分子增加 2LK＋2HC＋2EC，分母 16；版本间分数不可直接横比。评估由外部 NAVSIM 仓库执行，当前仓库只提供调用脚本。
